# INTERFACE WEB

 Este portfólio apresenta conceitos, técnicas e projetos relacionados ao desenvolvimento de **Interfaces Web**, abordando a criação de páginas modernas, organizadas e responsivas.

 ## Objetivo

 Conhecer os principais conceitos de Interface Web, utilizando:

- HTML
- CSS
- Design responsivo
- Layouts e componentes
- Formulários
- Navegação entre páginas

 ## Organização

- **Introdução/**: conceitos básicos sobre Interfaces Web
- **HTML/**: estrutura e organização das páginas
- **CSS/**: estilos, cores, fontes e layouts
- **Responsividade/**: adaptação das páginas para diferentes dispositivos
- **Projetos/**: atividades e interfaces desenvolvidas durante o curso

 ## Tecnologias utilizadas

- HTML5
- CSS
- Bootstrap
- Visual Studio Code
